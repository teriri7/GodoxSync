# GodoxSync · 神牛 X 防恶意引闪工具

> **研究用途声明**
>
> 本仓库和本项目发布包均不包含神牛原厂固件文件或完整的神牛原厂代码。适配配置中保留少量原始指令字节，用于核对补丁位置。工具仅在电脑上生成供离线分析的实验文件，无法直接刷写神牛设备。请勿将导出的实验文件刷入任何设备。

GodoxSync 是一款 Windows 桌面工具，用于研究神牛 X 系统的无线 ID 和同步字。它为选定的无线 ID 生成同步字，并在本机生成可供对比的实验文件。原厂固件由工具按需从神牛官网下载。

## 开始使用

1. 在 Windows x64 电脑上完整解压 `GodoxSync-Windows-x64.zip`，双击 **启动工具.cmd**。压缩包自带 Python 运行时。界面使用电脑上的 Microsoft Edge，RAR 固件包由 Windows 自带的 `tar.exe` 读取。
2. 把同一套灯光中的引闪器和闪光灯添加到右侧列表，核对每台设备的型号、卡口和硬件批次。X2T 以机身上的 Z01／Z02 标识为准。联网点击「下一步」，程序会下载对应的官网原包并校验固件大小和 SHA-256。下载中断时，可以留在设备页重试。
3. 选择无线 ID，预览并导出实验文件，在本机离线比较修改前后的字节。

## 界面说明

| 界面 | 操作 |
| --- | --- |
| **设备** | 顶部标签切换系列，左侧搜索型号，中间卡片选择卡口和固件版本。右侧保留跨系列的已选设备。点击「下一步」后显示下载进度，全部校验通过后进入无线 ID 步骤。 |
| **无线 ID** | 默认选中 90–99，可在 01–99 中自选。未选 ID 和 OFF 沿用原厂同步字。已有配对方案时，导入 `sync-plan.json` 即可复用。 |
| **导出** | 确认每个 ID 对应的同步字，或点击「重新随机」。选好位置后，工具按设备版本分目录保存固件，并附上本次的 `sync-plan.json`。 |

## 支持的设备

| 系列 | 型号 | 固件版本数 |
| --- | --- | ---: |
| X 系列 | X3、X3Pro、X1R、X2T、XPro P、XPro II、XR、XRS | 33 |
| V 系列 | V1、V1 mid、V1 Pro、V100、V480、V860 II、V860 III | 32 |
| TT 系列 | TT350P、TT685 | 6 |
| AD 系列 | AD100Pro、AD200、AD200Pro、AD200Pro II、AD300Pro、AD300Pro II、AD400Pro、AD400Pro II、AD600BM II、AD600Pro II、AD1200Pro | 12 |
| 其他闪光灯 | iT30Pro、P2400 | 7 |

共 **30 个型号、90 个固件版本**。TT685 和 V860 II 的 C／N／S／F／O 版使用 **G1（FRI）**，AD200 V2.6 使用 **G2（DFU）**，其他受支持版本使用 **G3（BIN）**。各型号支持的具体卡口和版本以程序内列表为准。

每版的官网地址、版本、文件大小、SHA-256 和补丁位置都记录在 `profiles.json`。下载并校验的原厂镜像只供当前运行会话复用。发布 ZIP 包含工具、运行时和固件下载配置。
